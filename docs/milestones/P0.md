# Phase 0 · before M1

Jobs that need the owner's accounts, passwords or root. The agent prepares scripts; the owner runs them.

- [ ] **P0-1** Create an empty private repo; protect `main` (PRs only, CI must pass)  
  Stops anyone, agent or human, pushing straight to main.
- [ ] **P0-2** Google Cloud: create a Web OAuth client with redirect `https://<host>/auth/callback`  
  Keep the client secret in the server env file, never in git. Needed before M1-04.
- [ ] **P0-3** Cloudflare: pick the hostname and add the tunnel rule with `deploy/add-tunnel-rule.sh`  
  Read it first. Do not touch the rules of the service already on the machine.
- [ ] **P0-4** Server: run `deploy/setup-host.sh` (user, data folder, systemd unit) after reading the diff  
  This is the sudo step. The agent never runs it.
- [ ] **P0-5** Choose the off-machine backup target and create a write-only key  
  Decision D9.
- [ ] **P0-6** Copy the 8 setup-kit files into the repo, adjust CLAUDE.md to your decisions, first commit  
  Day one.
