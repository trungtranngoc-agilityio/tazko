| D36 | M1-08 backups, checks, trash cleanup and rollback after a migration: how? | `tazko backup --data D --to B --keep-days N` copies control.db and each live company's tazko.db with SQLite's online backup API (WAL commits included, server keeps running), each company's `files/` and the `secret` file (needed to keep people signed in after a restore, so snapshots stay 700/600).
